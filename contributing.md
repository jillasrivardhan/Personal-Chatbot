# Contributing to Personal AI Chatbot

Thank you for your interest in contributing to this project!

Contributions, bug fixes, documentation improvements, and new features are welcome.

## How to Contribute

1. Fork this repository.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Install the project dependencies.
5. Make your changes and test them.
6. Commit your changes with a clear message.
7. Push your branch to your fork.
8. Open a Pull Request against the original repository.

## Development Guidelines

* Keep the code readable and modular.
* Follow Python naming conventions.
* Avoid unnecessary changes to unrelated files.
* Test your changes before submitting a Pull Request.
* Update the README when introducing significant features.
* Never commit API keys, `.env` files, or private information.
* Explain the purpose of your changes in the Pull Request.

## Areas for Contribution

* Improve query classification and routing.
* Improve personal knowledge retrieval.
* Enhance the Streamlit user interface.
* Add automated tests.
* Improve error handling and documentation.
* Optimize performance and reduce unnecessary API calls.

## Reporting Bugs

When reporting a bug, include:

* A clear description of the issue.
* Steps to reproduce it.
* Expected and actual behavior.
* Relevant error messages, with secrets removed.

Thank you for helping improve this project!
